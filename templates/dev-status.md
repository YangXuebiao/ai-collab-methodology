# 实现状态（dev-status）模板

> **用法**：实现过程中用，由**实现者**写，写完给**设计者和验收者**读。
> 它记录「做到哪了」和「我做了什么假设」—— 后者是整份文件里最重要的一节。

---

```markdown
# V{x.y.z} 实现状态

## 已完成
- [x] 原子项 1（文件:行号）
- [x] 原子项 2

## 未完成 / 阻塞
- [ ] 原子项 5 —— 卡在：<具体原因>

## 我做的假设      ← 最重要的一节
- 假设 <X> 是 <Y>，如果不是请纠正

## 偏离 spec 的地方
- 无 / <具体偏离 + 理由>

## 磁盘上的改动
- 修改：<文件清单>
- 未提交（等设计者审查）
```

---

## 「我做的假设」为什么单列

实现过程中一定会遇到 spec 没写清楚的地方。实现者会自己填一个，然后继续。

**这个填充如果不写下来，就永久丢失了**——将来出问题时，没人知道当初这里是"猜"的。
